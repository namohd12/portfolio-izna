# Nor Izna Mohd Isa ? Portfolio

Portfolio HTML, CSS dan JavaScript biasa. Tiada npm, React, pemasangan dependencies atau proses build diperlukan. Reka bentuk, kandungan resume, gambar, ikon dan fungsi daripada versi asal dikekalkan.

## Buka secara lokal

Klik dua kali `index.html` untuk buka dalam browser. Semua pautan aset menggunakan laluan relatif, jadi laman ini juga berfungsi dalam subfolder GitHub Pages.

Jika mahu pelayan lokal, Python boleh digunakan secara pilihan:

```sh
python -m http.server 8000
```

Kemudian buka `http://localhost:8000`.

## Fail utama

- `index.html` ? semua kandungan portfolio dan metadata SEO.
- `styles.css` ? reka bentuk asal dan susun atur responsif.
- `script.js` ? menu mudah alih, navigasi aktif dan butiran projek.
- `images/` ? gambar yang dioptimumkan serta sumber fotografi.
- `nor-izna-resume.pdf` ? resume untuk dimuat turun; nombor telefon, baris alamat dan bahagian rujukan telah dikeluarkan.
- `social-preview.png` dan `favicon.svg` ? pratonton perkongsian dan ikon laman.
- `.nojekyll` ? untuk penyajian fail statik secara terus oleh GitHub Pages.

## GitHub Pages

Repository: https://github.com/namohd12/portfolio-izna

Laman: https://namohd12.github.io/portfolio-izna/

Dalam **Settings ? Pages**, gunakan **Deploy from a branch**, pilih branch `main` dan folder `/ (root)`, kemudian simpan. Tiada arahan build diperlukan. Perubahan yang ditolak ke branch `main` akan diterbitkan oleh GitHub Pages.

Rujukan: [Dokumentasi rasmi GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Kemas kini

Edit teks secara terus dalam `index.html`. Gantikan `nor-izna-resume.pdf` apabila mengemas kini resume. Untuk menukar domain atau nama repository, kemas kini canonical URL, Open Graph URL dan `url` dalam structured data di bahagian `<head>`.

Laman ini menggunakan GitHub Pages; tiada sambungan kepada ChatGPT Sites diperlukan.
